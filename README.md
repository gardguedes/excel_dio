# Dashboard de Vendas no Excel

## 📌 Visão Geral
Este projeto foi desenvolvido como parte do **bootcamp da DIO: Klabin - Excel e Power BI Dashboards**.
Este projeto apresenta a construção de um **Dashboard de Vendas no Excel**, criado a partir de uma base de dados fictícia de planos de jogos do Xbox. O objetivo é transformar dados brutos em visualizações claras e funcionais, permitindo análises rápidas e insights sobre o desempenho das vendas.

O arquivo contém tanto os dados quanto elementos visuais já pré-definidos (cores, ícones e logos), utilizados na criação do dashboard.

---

## 🎯 Objetivo do Projeto
Converter dados brutos em informações visuais acessíveis, organizadas e úteis para apoiar:
- A análise de desempenho de vendas;
- A identificação de padrões e oportunidades;
- A tomada de decisões baseada em dados.

---

## 🛠️ Tecnologias Utilizadas
- **Microsoft Excel**
  - Tabelas Dinâmicas
  - Gráficos e elementos visuais
  - Segmentações de dados (filtro temporal)
  - Layout e personalização de planilhas

---

## 📂 Dados Utilizados
A base de dados fictícia incluía:
- Informações de vendas de diferentes planos de jogos do Xbox;
- Indicações de cores e ícones para compor o dashboard;
- Logos e imagens ilustrativas.

A análise envolveu explorar colunas como:
- Tipo de plano
- Valor da assinatura
- Jogos adquiridos
- Frequência de compra
- Informações de assinatura (YES/NO)

---

## 🔄 Processo de Criação

### **1. Entendimento da Base de Dados**
- Exploração das colunas disponíveis e tipos de informações.
- Identificação dos indicadores mais relevantes para análise.
- Criação da primeira **tabela dinâmica**, permitindo segmentações e análises mais profundas.

### **2. Definição das Perguntas de Negócio**
As perguntas orientaram a criação dos visuais. Foram selecionadas três questões principais:

1. **Qual o faturamento total de venda de planos anuais?**  
   - Foi criado um gráfico de barras comparando clientes com assinatura (YES) e sem assinatura (NO).

2. **Qual o total de vendas das assinaturas do EA Play?**  
   - Exibição de um único valor agregado.

3. **Qual o total de vendas das assinaturas do Minecraft Season Pass?**  
   - Também exibido como valor agregado.

Além disso, foi adicionado um **filtro temporal** (mensal, trimestral e anual), aplicado a todo o dashboard.

### **3. Construção do Dashboard**
- Criação de uma nova aba exclusiva chamada **"Dashboard"**.
- Definição do layout: background, posição do título, área dos visuais e barra lateral para filtros.
- Conexão dos gráficos às respectivas tabelas dinâmicas, garantindo atualização conjunta.

### **4. Ajustes Finais e Otimização**
- Ocultação de abas, barra de fórmulas e títulos para foco total no dashboard.
- Ativação do modo de exibição em tela inteira.
- Ajustes de cores, fontes e espaçamentos para melhorar a experiência do usuário.

---

## ▶️ Reprodução do Projeto
Para reproduzir este dashboard:
1. Abra o arquivo Excel do projeto.
2. Verifique a aba **Dados** para explorar a base bruta.
3. Confira as tabelas dinâmicas utilizadas para alimentar os visuais.
4. Acesse a aba **Dashboard** para visualizar o painel final.
5. Utilize o filtro temporal para alterar a visão das métricas.

---

## 🧾 Conclusão
Este projeto demonstra como dados brutos podem ser organizados e transformados em um dashboard funcional, visualmente atraente e orientado para responder perguntas de negócio. O processo reforça a importância de entender a base de dados, definir métricas relevantes e aplicar boas práticas de design para entregar análises mais eficientes.

A construção do dashboard consolida habilidades essenciais para profissionais que trabalham com organização, visualização e interpretação de dados no Excel.
